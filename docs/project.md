# 導入先で決めるプロジェクト情報

ここにプロジェクトの事実と既存正本への入口を置きます。以下はテンプレート自体の初期値です。移植時に実際の値へ更新し、未決定を推測で埋めません。

| 項目 | 現在の値 |
| --- | --- |
| 目的 | エージェント開発環境を再利用する |
| 対象外 | アプリ固有実装、アカウント移行、自動課金、既存環境の置換 |
| 言語・runtime | Python 3.11以上（標準ライブラリ）、Bash、macOS/Linux |
| 統合先 | main。developは作成・利用していない |
| 検証 | `python3 scripts/check.py` |
| build / package | なし。導入先で実buildコマンドを設定する |
| GUI | テンプレート検証には不要。導入先の必要Caseで個別指定 |
| CI | `harness-checks`。サーバーrequired設定は導入時にreadbackする |
| レビュー | writerとは別のセッション。固定HEAD/baseと受入を記録 |
| 作業管理 | GitHub Issues / PR。ProjectとMilestoneは実目標に応じて設定 |
| 認証・秘密 | 正規ログイン、OSの資格情報保存、環境変数。Git管理しない |

導入先では要件、source/test配置、実行コマンド、支援ツール、互換性、リリース条件の正本へリンクします。全文を重複させません。
